# Arkanoid: where it stands (2026-10-14)

The breakout example (`examples/arkanoid`). It is loaded headless by `node tools/smoke.mjs <dir>` with every game.

- `ACTIVE/`: nothing open.
- `COMPLETED/`: nothing recorded; the game predates this folder.

If work on it starts, its plan goes in `ACTIVE/` and moves to `COMPLETED/` when done.
